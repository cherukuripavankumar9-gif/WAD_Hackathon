## 🔊 **If Audio Doesn't Play:**

1. **Check Volume:** Bottom right slider should be above 0%
2. **Check Mute:** Speaker icon should NOT be crossed out (🔊 not 🔇)
3. **Browser Volume:** Right-click browser tab, ensure not muted
4. **System Volume:** Check Windows volume is up
5. **Try Another Song:** Maybe one file has an issue
6. **Refresh Page:** Press F5 or Ctrl+R
